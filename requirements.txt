Score App Requirements
======================

This repository is a Node.js + React application.
Install dependencies with:

  npm install

Recommended runtime
-------------------
- Node.js 20+ recommended
- npm 10+ recommended
- Writable local directories:
  - server/data
  - uploads
- Open local ports:
  - 5173 for Vite
  - 3001 for Express + Socket.IO

Environment variables
---------------------
- PORT=3001
  Optional. Express port. Defaults to 3001.

- JWT_SECRET=your-secret
  Optional in development. Required in production.

- CORS_ORIGIN=http://localhost:5173,http://localhost:4173
  Optional. Comma-separated list of allowed frontend origins.

Built-in data/storage behavior
------------------------------
- SQLite database file: server/data/score.db
- Local uploaded videos directory: uploads/
- Official game catalog seeding runs on server startup
- JWT auth token is stored in the browser's localStorage
